# Changelog

All notable changes to FlowMiner are documented in this file.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).
FlowMiner uses [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added — audit-fixes batch

- **GHCR releases** — GitHub Actions workflow (`release.yml`) builds and pushes
  multi-arch (`linux/amd64`, `linux/arm64`) images to GHCR on every `v*` tag so
  self-hosters can pull a pinned release instead of building from source.
- **Pinned image tags in `docker-compose.yml`** — production compose now
  references `ghcr.io/flowminer/backend:0.1.0` / `ghcr.io/flowminer/frontend:0.1.0`
  rather than locally-built `:local` tags; a local-build override path is
  preserved via `docker-compose.dev.yml`.
- **CHANGELOG** — this file; Keep-a-Changelog format, updated on every release.
- **Discrete-event simulation engine** (Simod-style) — simulate a discovered
  process model with configurable resource pools and arrival rates to predict
  cycle-time distributions before deploying any real changes.
- **M/M/c queue mining with wait-time decomposition** — identify which activities
  are bottlenecks by fitting an M/M/c queuing model and decomposing observed
  waiting times into service-time vs. resource-contention components.
- **JSD-based concept drift detection** — detect and localise points in time
  where the process changed significantly using Jensen–Shannon divergence on
  sliding windows of the event log.
- **Split Miner v2 with concurrency detection** — improved process-discovery
  algorithm that reliably handles concurrency and produces cleaner, smaller
  models; adds richer Declare constraint templates (responded-existence,
  co-existence, chain-succession, and more).
- **Event-log extraction copilot** — AI-assisted wizard that turns raw database
  tables or CSV exports into a standards-compliant XES/CSV event log with
  minimal manual mapping.
- **Plain-language Explain button** — one-click natural-language summary of
  bottleneck and conformance findings, generated by the configured LLM provider.
- **DBSM single-score bottleneck severity ranking** — normalised 0–100 severity
  score combining wait-time, frequency, and resource-utilisation signals so
  bottlenecks can be ranked at a glance.
- **Stochastic conformance via EMD + REACH alignment notes** — earth-mover
  distance on activity distributions complements token-replay fitness; alignment
  notes surface the costliest deviation moves directly in the UI.
- **DMN 1.4 XML export** — discovered decision rules can be exported as
  standards-compliant DMN 1.4 XML for import into Camunda, Signavio, etc.
- **Cognitive-complexity score badge + progressive disclosure** — each process
  view now shows a complexity badge; panels with many details are collapsed by
  default and expand on demand to reduce information overload.
- **Smoother self-host onboarding** — ops CLI helpers, a `SEED_SAMPLE_DATA_ON_FIRST_BOOT`
  flag, and a `DEMO_MODE` env var (replaces the old `docker-compose.demo.yml`).
- **System health endpoint** — `/health` and `/ready` endpoints expose
  dependency status (DB, Redis, Celery) for external uptime monitors.

## [0.1.0] — 2025-01-01

Initial public release extracted from the internal monorepo.

### Added

- FastAPI + SQLAlchemy 2 async backend with Alembic migrations.
- React 18 + TypeScript (strict) + Vite + Tailwind CSS + Zustand frontend.
- XES and CSV event-log upload and management.
- Process discovery: Inductive Miner, Heuristics Miner, Alpha Miner (via pm4py).
- Conformance checking: token-replay fitness and precision.
- Performance analysis: activity duration statistics, resource utilisation heatmaps.
- Celery + Redis task queue for long-running mining jobs.
- PostgreSQL persistence; optional encryption of stored API keys at rest.
- Docker Compose production stack with Dokploy/Traefik integration.
- Multi-provider LLM integration (OpenRouter, Anthropic, OpenAI) with a
  no-credential null fallback so the UI works without any API keys.
- SMTP alert hooks (optional).
- Role-based access control with JWT authentication.
