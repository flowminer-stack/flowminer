# FlowMiner capture agent — OPTIONAL platform capture-backend dependencies.
#
# Core deps (the FlowMiner SDK + httpx) live in pyproject.toml and resolve
# from the local workspace — there is NO PyPI package named "flowminer".
# Install the core + your platform backend with uv:
#
#     uv sync --extra linux        # (or --extra macos / --extra windows)
#
# or with plain pip from the repo root:
#
#     pip install ./sdk && pip install ./tools/capture_agent
#
# The platform backends below are imported lazily by agent.py; install only
# the one(s) for your OS (equivalently, use the matching pyproject extra).

# ── Windows ──────────────────────────────────────────────────────────────────
# Uncomment the line(s) for your preferred Windows backend:
# pygetwindow>=0.0.9   # easiest — pip install pygetwindow
# pywin32>=306         # lower-level Win32 API — pip install pywin32

# ── macOS ─────────────────────────────────────────────────────────────────────
# AppKit and Quartz ship with the system Python on macOS.
# If you're using a standalone Python distribution, install pyobjc:
# pyobjc-framework-Cocoa>=10.0    # provides AppKit
# pyobjc-framework-Quartz>=10.0   # provides Quartz

# ── Linux (X11) ───────────────────────────────────────────────────────────────
# Uncomment one of:
# ewmh>=0.1.6          # python-ewmh; also needs python-xlib
# python-xlib>=0.33    # required by ewmh
#
# Or ensure xdotool / wmctrl is installed via your package manager:
#   sudo apt install xdotool
#   sudo apt install wmctrl
