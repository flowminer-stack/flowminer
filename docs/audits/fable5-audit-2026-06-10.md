## Overall Assessment
This is one of the better-grounded competitive reports I have reviewed. It adopted nearly every adversarial correction from verification (16 hidden pages not 26, 21 controls not 18, 6 filter categories not 9, 9 KPI scalars not 7, 9 recipes not 6, the demo-kit and onboarding-reopen disproofs), it correctly avoided recommending things that verification showed already exist (demo infra, ROI layer, streaming backend, templates gallery), and its central thesis — capability is not the constraint, distribution and discoverability are — is independently supported by both the capability map and my spot-checks (zero git tags, `<you>` placeholders in 3 files, full deploy/demo kit unreferenced in README, 7 internal-only action types). The Honest Caveats section is genuinely honest about the absence of user-behavior data. Where it falls short: (1) it omits the verified guided-methodology/goal-first finding entirely — the single market pain with the strongest evidence (question formulation, 89% affected, lowest solvability) gets no roadmap line; (2) it omits the capability map's silent-degradation cluster (causal silently falls back to a Pearson graph still labeled causal, DES fallback skips queue contention, EMD is a rank approximation with no qualifier, OPerA hard-errors without ocpa) — a direct threat to the depth-first repositioning the report itself recommends, since marketing LiNGAM/DES/stochastic-conformance on silently-degrading optional deps reproduces the exact 'features advertised before ready' complaint that drives Celonis defections; (3) the exec summary lists write-back as top-5 move #5 but the roadmap shelves it at LATER #15 — an unresolved internal contradiction; (4) minor sequencing and framing errors (dvh fix parked in NEXT despite being a one-liner and a precondition for the demo link; Apromore archival mis-sequenced as 'after' the Salesforce acquisition when it preceded it, and the 'shopping right now' urgency is 9 months stale). None of these invalidate the report's direction; they sharpen it. Overall: well-grounded, fair, actionable, with a handful of buried items and one internal contradiction to fix.

## Strategic Verdict — What We Actually Need
> The report's verdict survives independent audit and my spot-checks confirm its load-bearing facts: FlowMiner has verified Celonis-class depth (stochastic conformance, queue mining, LiNGAM, DES, predictive+SHAP, OCEL 2.0, a 9-tool MCP server, Rust acceleration) and is losing not on capability but on being unfindable — externally (no tags, placeholder URLs, an undeployed demo kit, zero distribution surface) and internally (~16 differentiating analyses reachable only via ⌘K, an AI layer that renders an error dump on fresh installs, a hidden data-quality report). What we actually need, in order: one week of S-effort distribution and honesty fixes (tag, placeholders, demo deploy with rust_accel and optional deps baked in, AI-no-key cards, quality banner, shortcut/tour/dvh papercuts, depth-first copy plus published support pricing); then convert depth into self-service (browsable Analyses catalog plus the goal-first chooser the report dropped, four new chat tools, ProcessView calm-down, filter unification, connector test-config) while shipping a Jira-only write-back slice to bank the anti-EMS story early rather than parking it in LATER; and throughout, guard the depth-first repositioning with degradation honesty (bundle lingam/shap/simpy/ocpa, label fallbacks) so FlowMiner never becomes the 'advertised before ready' vendor its own research shows buyers punish. The GTM thesis itself — Apromore exodus, sovereignty beachhead, MCP/dev-tool channel — remains an untested bet, so run the report's cheap test (demo link, one comparison article, the MCP blog post) and measure before funding anything heavier; build nothing new until what already exists can be found.

### Rationale detail
**1. Ship the distribution unblock: push v0.1.0, replace placeholders, claim coordinates** _(impact: critical, effort: S, evidence: strong, seq: now — first; everything else inherits credibility from it)_

Buyers fleeing Celonis/ARIS/Apromore over vendor-stability fear (the research's strongest trust theme) hit a pre-launch placeholder repo. **2. Fix the fresh-install embarrassments before anything goes public** _(impact: high, effort: S, evidence: strong, seq: now — must land before the demo URL enters the README)_

Verified: with no LLM key, Mission Control renders the null-provider's raw env-var dump AS the executive briefing (worse than absence — looks broken), llm_configured is consumed by only 2 of 5+ AI surfaces; the '/' shortcut silently fails on a wrong selector; ⌘K is absent from the shortcuts help; the OCPM tour spotlights nothing; backdrop-click permanently kills the tour; 4 canvas pages clip on mobile (100vh). Every one is an S fix, and Disco-style polish is the explicit bar the target segment judges by.

**3. Deploy demo.flowminer.io from the existing kit — with rust_accel and optional deps baked in** _(impact: critical, effort: M, evidence: strong, seq: now — after items 1-2; ops work plus a one-line README change)_

Critical addendum the report missed: the image must build rust_accel (else mining runs slow Python fallbacks) and include lingam/shap/simpy so the demo shows real depth, plus the HR_Onboarding logs so the comparison view is demoable. Incumbents require 'multiple sales calls before any access' — an instant live demo is the single biggest funnel asymmetry available.

- A native mobile app — the verified gap is a clipped canvas (one-line dvh fix) plus, at most, a single read-only mobile KPI/alerts route on the existing PWA shell; IBM's complaint does not justify a codebase
- Task-mining depth (richer capture agent, OCR/screenshots, managed rollout) — verified prototype ceiling plus HR/works-council governance overhead makes it XL with uncertain payoff; keep and surface only the verified-differentiated cross-link endpoint
- A Disco .dsc binary parser — Disco and Apromore CE both export XES, which FlowMiner already ingests; the migration wizard is auto-mapping UX on the XES path, not a proprietary-format reverse-engineering project
- A licensed external benchmark dataset (APQC-style peer data) — the verified path is wiring the existing template KPI targets into BenchmarkPage as clearly-labeled, overridable reference targets; claiming peer data FlowMiner doesn't have walks into Signavio's 'invalid hardcoded assumptions' trap
- A third AI chat surface, or new analysis pages of any kind — there are already two unexplained chat UIs and ~16 undiscoverable analyses; consolidate and surface before adding surface area
- Marketing copy for unverified-maturity features (DMN export, sustainability/carbon, counterfactual, the partial SaaS connectors' fetch depth) until someone reads the code — the report's own caveat, worth enforcing as a hard rule
- Full RPA-bridge integrations (UiPath/Power Automate orchestration) — the Jira/ServiceNow write-back slice covers the close-the-loop story; RPA bridges serve a segment FlowMiner isn't targeting yet
